# 도표 종류 (visual)

카드의 `visual` 필드에 넣을 수 있는 시각 자료 목록입니다.
**영상에는 마우스 오버가 없으므로 모든 수치는 화면에 직접 라벨로 찍힙니다.**
색은 "하나만 강조, 나머지는 회색" 원칙을 따릅니다 — 4초 안에 시선은 한 곳으로 가야 합니다.

---

## 무엇을 쓸지 고르는 법

| 이 카드가 하려는 말 | 쓸 도표 |
| --- | --- |
| **순위·TOP N 을 보여준다** | **`ranklist`** |
| 숫자 하나가 핵심이다 | `stat` |
| 항목끼리 크기를 비교한다 | `bar` |
| 시간이 지나며 변했다 | `trend` |
| 전체 중 얼마를 차지한다 | `donut` |
| 단계·흐름·인과관계가 있다 | `flow` |
| 계산 과정을 보여준다 | `calc` |
| 대상인지 아닌지 따진다 | `checklist` |
| A와 B가 어떻게 다른가 | `table` |
| 언제 무엇을 해야 하나 | `timeline` |

도표가 억지스러우면 넣지 않아도 됩니다. 다만 **글자만 있는 카드가 많아질수록
"자막 슬라이드쇼"에 가까워진다**는 점은 감안하세요.

### 항목이 많을 때 — 지우지 말고 나누세요

도표는 항목 수에 맞춰 글자·행 높이를 **자동으로 줄입니다**(`src/lib/density.ts`).
다만 읽을 수 있는 하한(26px)에 닿으면 더는 못 줄이고 잘립니다.

**순위·목록이 원문의 핵심이라면 항목을 지우면 안 됩니다.** 카드를 나눠서 이어 보여주세요.
`npm run check` 가 넘치는 카드를 찾아 몇 장으로 나눌지까지 알려줍니다.

---

## headline — 1번 카드의 주제 배너 ⭐

도표는 아니지만 첫 화면에서 가장 중요한 요소라 여기 같이 적습니다.

```json
{ "type": "hook", "headline": "공기업 평균연봉 TOP 16",
  "title": "1위는 1억을\n넘깁니다" }
```

`headline` 은 **1번 카드에만** 넣습니다. accent 색 배너로 제목 위에 크게 박힙니다.
첫 프레임이 썸네일로 잡히므로, 여기서 "무슨 영상인지"가 읽혀야 합니다.

- 주제 + 범위가 다 들어간 **정확한 한 줄** (8~20자)
- `title` 은 배너를 되풀이하지 말고 **후킹 문장**을 씁니다
- 글자 크기는 폭에 맞춰 자동(최대 56px). 20자를 넘으면 접히므로 `npm run check` 가 경고합니다

## ranklist — 순위 목록 / TOP N ⭐

```json
{ "kind": "ranklist", "totalRanks": 20, "items": [
  { "rank": 1, "label": "한국수력원자력", "value": "1억 847만 원",
    "barValue": 10847, "highlight": true },
  { "rank": 2, "label": "한국가스공사", "value": "1억 609만 원", "barValue": 10609 }
] }
```

**"TOP 20" 이 원문이면 시청자가 보러 온 건 20개 전부입니다.** 상위 몇 개만 뽑고
나머지를 설명으로 때우면 영상이 죽습니다. 이 도표로 전부 보여주세요.

- `value` 는 화면에 찍힐 문자열 그대로 (`"1억 847만 원"`)
- `barValue` 는 막대 길이용 숫자 (선택). 0부터 그리므로 값이 비슷하면 막대 차이도 작습니다
- 한 카드에 **최대 14행**, 보기 좋은 건 7~10행
- 나눠 실을 땐 `rank` 를 직접 지정하면 번호가 이어집니다. `totalRanks` 에 전체 개수
- `highlight` 는 한 카드에 하나만 (다른 도표와 같은 "하나만 강조" 규칙)

행이 하나씩 순서대로 올라오기 때문에, **다음 순위를 기다리게 되어 시청 지속에도 유리합니다.**

끝까지 보게 하려면 **낮은 순위부터 거꾸로** 싣는 것도 방법입니다
(20~14위 → 13~7위 → 6~1위). `rank` 를 직접 지정하므로 순서는 자유입니다.

## stat — 핵심 숫자 하나

```json
{ "kind": "stat", "value": "23,000", "unit": "원",
  "caption": "카드사별 평균 잔여 포인트 × 5장 기준, 직접 산출",
  "delta": { "text": "작년 대비 +12%", "dir": "up" } }
```
`caption` 에 **어떻게 나온 숫자인지** 적으세요. 출처 없는 큰 숫자는 신뢰를 깎습니다.
`delta` 는 선택이며 `dir` 이 `up` 이면 초록, `down` 이면 빨강으로 표시됩니다.

## bar — 가로 막대그래프

```json
{ "kind": "bar", "unit": "원", "items": [
  { "label": "A카드", "value": 12400, "highlight": true },
  { "label": "B카드", "value": 6850 },
  { "label": "D카드", "value": 900, "note": "최소 전환 금액 미달" }
] }
```
한 카드에 **최대 8개**(보기 좋은 건 3~5개). `highlight` 를 아무 데도 안 주면 최댓값이 자동 강조됩니다.
세로 화면에서는 가로 막대가 유리합니다(긴 한글 라벨이 그대로 들어갑니다).

## trend — 꺾은선 그래프

```json
{ "kind": "trend", "unit": "억", "points": [
  { "label": "2021", "value": 820 }, { "label": "2025", "value": 1180 }
] }
```
점은 **4~6개**. 선이 왼쪽에서 오른쪽으로 그려지고 마지막 값에만 큰 라벨이 붙습니다.
(모든 점에 숫자를 찍으면 4초 안에 읽히지 않습니다.)

## donut — 전체 중 비중

```json
{ "kind": "donut", "centerLabel": "100%", "slices": [
  { "label": "그냥 소멸", "value": 62, "highlight": true },
  { "label": "현금 전환", "value": 23 }
] }
```
조각은 **3개 이하**. 강조 조각만 포인트 컬러, 나머지는 회색 단계로 칠해집니다.
값은 자동으로 % 로 환산됩니다.

## flow — 관계 도표 ⭐

```json
{ "kind": "flow", "direction": "down", "nodes": [
  { "label": "본인 인증", "note": "휴대폰 또는 공동인증서" },
  { "label": "계좌 입력 후 신청", "note": "1포인트 = 1원" },
  { "label": "영업일 기준 입금", "highlight": true }
] }
```
"A라서 → B가 되고 → 그래서 C" 구조를 말이 아니라 그림으로 보여줍니다.
세로(`down`)는 한 카드에 **최대 7개**(보기 좋은 건 3~4개). `direction` 은 `down`(기본) 또는 `right`.
가로는 항목이 짧고 3개 이하일 때만 쓰세요.

## calc — 직접 계산한 내역 ⭐

```json
{ "kind": "calc",
  "lines": [ { "label": "A카드 (주력 카드)", "value": "12,400원" } ],
  "result": { "label": "실제 입금액", "value": "22,370원" } }
```
"얼마다"라고 말만 하는 것과 계산 과정을 보여주는 것은 다릅니다.
**직접 조사했다는 가장 강한 증거**라서, 한 영상에 한 장은 넣는 게 좋습니다.

## checklist — 해당 / 비해당

```json
{ "kind": "checklist", "items": [
  { "text": "3년 넘게 쓴 카드가 있다", "ok": true },
  { "text": "작년에 이미 전액 현금화했다", "ok": false }
] }
```
`ok: true` 는 초록 ✓, `false` 는 빨강 ✕. 색과 기호를 같이 써서 색만으로 구분되지 않게 했습니다.
한 카드에 **최대 10개**(보기 좋은 건 3~5개). 글자가 길면 절반으로 잡으세요.

## table — 2열 비교표

```json
{ "kind": "table", "headers": ["기본 포인트", "제휴 포인트"], "highlightCol": 1,
  "rows": [ { "label": "소멸 기한", "a": "보통 5년", "b": "1년도 있음" } ] }
```
한 카드에 **최대 10행**(보기 좋은 건 3~5행). `highlightCol` 로 강조할 열(0 또는 1)을 지정합니다.

## timeline — 시점별 변화

```json
{ "kind": "timeline", "items": [
  { "when": "지금", "label": "포인트 잔액 조회", "highlight": true },
  { "when": "연말", "label": "미신청분 순차 소멸" }
] }
```
신청 마감, 제도 변경일처럼 **"언제"가 핵심**인 정보에 씁니다. 한 카드에 최대 8개.

## 색 테마 (accent)

`script.json` 최상단의 `accent` 로 영상 전체 톤을 바꿉니다.
**주제가 바뀌면 테마도 바꾸세요.** 모든 영상이 같은 색이면 한 영상처럼 보입니다.

테마는 포인트 색만 바꾸는 게 아닙니다. **배경색 전체 · 그라데이션 방향 ·
빛이 들어오는 자리 · 배경 질감** 네 가지가 같이 바뀌어서, 화면 전체가 다른 영상처럼 보입니다.

| 값 | 배경 | 빛 | 질감 | 어울리는 주제 |
| --- | --- | --- | --- | --- |
| `gold` (기본) | 깊은 남색 | 위 가운데 | 격자 | 지원금, 환급, 포인트 |
| `mint` | 짙은 청록(숲) | 왼쪽 아래 | 사선 | 신청 방법, 제도 설명 |
| `coral` | 자줏빛 적갈 | 오른쪽 위 | 점무늬 | 놓치면 손해, 마감 임박 |
| `violet` | 진한 보라 | 아래 가운데 | 동심원 | 상품 비교, 데이터 분석 |
| `ice` | 무채색 강철 | 왼쪽 위 모서리 | 가로 주사선 | 통계, 시장 동향 |

다섯 장을 한 번에 비교하려면 테마별로 `accent` 만 바꿔가며 `npm run still -- 0` 을 돌리면 됩니다.

새 테마를 추가할 때는 `src/theme.ts` 의 `ACCENTS` 에 항목 하나를 넣습니다.
`bg` 네 단계는 **중간 단계를 `#122350` 보다 밝게 잡지 않습니다.**
그보다 밝아지면 도표 색의 대비 검증이 깨집니다(`src/components/chartTheme.ts` 참고).

## 도표 확인용 데모

`docs/examples/ranking-demo.json` 에 순위 구성(ranklist 2장 + 계산 + 주의점) 데모가,
`docs/examples/charts-demo.json` 에 막대·꺾은선·도넛 데모가 들어 있습니다.
렌더링 없이 한 장만 확인하려면:

```bash
npx remotion still CardNews output/test.png --frame=100 --props=docs/examples/charts-demo.json
```
