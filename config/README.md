# 연출 설정 (`config/style.json`)

훅 문구 형태·모션·순위 공개 순서·오디오 값을 **코드를 고치지 않고** 바꾸는 곳입니다.
고친 뒤 다시 렌더하면 반영됩니다. 항목을 지워도 기본값으로 돌아가니 안전합니다.

---

## `hook.style` — 1번 카드 훅 문구 형태

쇼츠는 **첫 3초**에서 절반이 나갑니다. 그 3초 문장이 질문형이면
("적금 2.8%가 아쉽다면?") 답을 기다려야 하는데, 기다릴 이유가 없어서 넘깁니다.

| 값 | 뜻 | 예시 |
| --- | --- | --- |
| `number-first` (기본) | 결론·숫자를 먼저 깐다 | "1위는 1억을 넘깁니다" |
| `comparison` | 아는 크기로 환산해 던진다 | "4년이면 중형차 한 대 값" |
| `provocative` | 손해·오해를 찌른다 | "은행 적금에 묶어두면 손해 보는 이유" |
| `question` | 예전 방식(질문형) | "1위는 어디일까" |

> `provocative` 는 **원문에 있는 사실 안에서만** 씁니다.
> 과장 훅은 조회수보다 신뢰를 먼저 깎고, 채널 단위로 평가되는 수익화에 불리합니다.

## `motion` — 글자 연출

| 값 | 뜻 |
| --- | --- |
| `titleReveal` | `word` = 단어를 하나씩 띄운다(기본) / `line` = 줄 단위 |
| `wordStaggerFrames` | 단어 사이 간격(프레임). 30fps 기준 2 = 0.067초 |
| `emphasis.enabled` | 숫자·순위·퍼센트 덩어리를 강조할지 |
| `emphasis.scale` | 강조 글자를 몇 배로 키울지 (1 = 안 키움) |
| `emphasis.bounce` | 튕기며 등장할지 |
| `emphasis.color` | `bright` / `primary` / `soft` — 테마 색 중 하나 |

강조 대상은 자동으로 찾습니다(`src/lib/emphasis.ts`). `1,128만 원` `8.25%` `TOP 20` `1위`
처럼 **단위·조사까지 한 덩어리로** 묶어서 키웁니다. 한 줄이 온통 숫자면(`1위 2위 3위`)
강조가 의미 없으므로 자동으로 해제됩니다.

> ⚠️ **1번 카드는 0프레임이 완성된 화면**이어야 합니다(유튜브·인스타가 첫 프레임을
> 썸네일로 잡아갑니다). 그래서 1번 카드는 등장 연출을 건너뛰고 **강조만** 적용됩니다.
> 썸네일에서도 숫자가 커 보여야 눌리기 때문입니다.

## `rank.reveal` — 순위 공개 순서

목록이 위에서 아래로 그냥 깔리면 "다 봤다"는 느낌에 중간에 나갑니다.

| 값 | 뜻 |
| --- | --- |
| `bottom-up` (기본) | 대본에 적힌 순서대로 |
| `winner-first` | **1위를 먼저 꽂고** 나머지를 잇는다 |
| `countdown` | 아래쪽부터 거꾸로 — 3위 → 2위 → 1위 |

카드마다 다르게 하려면 대본의 `visual` 에 `"reveal": "winner-first"` 를 넣으면
그 카드만 그 순서를 씁니다. **자리는 그대로 두고 등장 타이밍만 바뀝니다** —
순위 자체가 뒤섞이지는 않습니다.

## `audio`

| 값 | 뜻 |
| --- | --- |
| `speed` | 기본 재생 속도. 허용값 `1` / `1.1` / `1.25` |
| `gapSec` | 카드 사이 여백(초) |
| `bgm.*` | 배경음악 — 아래 참고 |

> 4단계 화면에서 고른 속도·여백이 있으면 **그 값이 우선**합니다.
> 여기 값은 "새 작업을 시작할 때의 기본값"입니다.

> **2배속은 넣지 않습니다.** 도표를 읽을 시간이 사라지고 목소리가 부자연스러워져
> 이 프로젝트가 피하려는 "양산형" 인상을 줍니다.
