# 배경음악 두는 곳

저작권 없는 음원(mp3 등)을 **이 폴더에** 넣으면 4단계 "배경음악"에서 골라 쓸 수 있습니다.

- 앱에서 **들어보고 고를 수 있고**, 고른 곡은 렌더할 때 자동으로 깔립니다.
- 말하는 동안에는 음악이 자동으로 낮아집니다(목소리를 가리지 않게).
- 곡이 영상보다 짧으면 자동으로 이어 붙이고, 길면 잘라냅니다.

## ⚠️ `public/audio/` 에 넣지 마세요

거기는 합친 내레이션이 들어가는 **작업 폴더**라,
4단계의 **[전부 지우고 처음부터]** 를 누르면 통째로 비워집니다. 음악이 다 지워집니다.
(저장소에서도 제외되는 폴더라 올라가지도 않습니다)

## 넣는 방법

깃허브에서 이 폴더로 들어가 **Add file → Upload files** 로 올리거나,
내 컴퓨터에서 이 폴더에 복사한 뒤 커밋하면 됩니다.

파일 이름에 공백·따옴표가 있어도 괜찮습니다.

> `config/` 나 `config/bgm/` 에 올려둔 음원도 읽습니다(예전에 그리로 올린 경우를 위해).
> 다만 `config/` 는 원래 설정 파일 자리라, 여기로 옮기는 편이 깔끔합니다.
