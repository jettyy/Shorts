기사·블로그 글을 붙여넣으면, **클로드코드가 직접 분석해서 도표가 들어간
세로형(1080×1920) 쇼츠 영상**을 만들어주는 프로젝트입니다.

- 📊 **도표 중심** — 순위표·막대·꺾은선·도넛·관계도·계산표·체크리스트·타임라인 10종
- 🧩 **내용에 맞춰 구성이 바뀜** — 순위 원문이면 순위를 전부, 비교 원문이면 비교표로
- 🎯 **첫 화면에 주제 배너** — "한국 부자 TOP 20" 처럼 무슨 영상인지 바로 보임(썸네일 겸용)
- 🎙 **내레이션 녹음 대본 자동 생성** — 직접 녹음해서 얹으면 완성
- 🔑 **API 키 필요 없음** — 분석은 클로드코드가 직접 합니다. `.env`도, 과금도 없습니다
- ♻️ **재사용 템플릿** — 새 주제는 `src/script.json`만 갈아끼우면 끝

## ⚠️ 먼저 알아야 할 것 — 왜 "그냥 카드뉴스"가 아닌가

유튜브는 **"설명·해설·교육적 가치가 거의 없는 이미지 슬라이드쇼 또는 스크롤 텍스트"**를
수익화 불가 사례로 명시합니다. 개별 영상이 아니라 **채널 전체**를 보고 판단합니다.

기사를 AI로 요약해서 자막 카드만 넘기는 영상을 반복 업로드하면 위험합니다.
그래서 이 프로젝트는 처음부터 **요약본이 아닌 해설 영상**이 나오도록 설계돼 있습니다.

| 위험한 방식 | 이 프로젝트의 방식 |
| --- | --- |
| 원문 문장을 그대로 옮김 | 사실만 가져와 다시 씀 (`npm run check`가 베낀 문장 검사) |
| 글자만 넘어감 | 카드마다 도표·그래프 |
| 요약으로 끝 | **직접 계산(`example`) + 주의점(`caveat`)** 카드 필수 |
| 해설 없음 | 카드마다 내레이션, 녹음 대본 자동 생성 |
| 영상마다 똑같은 화면 | 주제별 테마 5종 + 도표 10종 + 내용별 구성 5종 |
| 출처 불명 | 마지막 카드에 출처·확인 기준일 자동 표기 |

**그래도 승인을 보장할 수는 없습니다.** 최종 판단은 유튜브가 합니다.
다만 "직접 조사·해설했다"는 근거를 영상 안에 남기는 것이 핵심이고,
그 근거를 만들기 쉽게 도구를 짜뒀습니다.

> 가장 효과가 큰 한 가지: **본인 목소리 녹음을 얹는 것.**
> 앱 3단계에서 대본을 보면서 바로 녹음하고, 들어보고, 다시 녹음할 수 있습니다.

## 🚀 이렇게 씁니다 — 브라우저 앱

```bash
npm install   # 처음 한 번만 (필수)
npm start
```

브라우저에서 **http://localhost:4321** 을 열면 4단계 화면이 나옵니다.

> ⚠️ **`npm install` 을 빼먹으면** 서버는 켜지고 대본까지는 만들어지지만,
> 녹음 합치기와 영상 렌더링에서 실패합니다.
> 그래서 서버가 켜질 때와 앱 첫 화면에서 설치가 덜 됐는지 먼저 알려줍니다.

### 1단계 · 원문 붙여넣기
기사나 블로그 글을 통째로 붙여넣고, 출처(제목·매체·URL)와
영상 테마·카드 장수를 고른 뒤 **[대본 만들기]**.

> 확인 기준일은 따로 입력하지 않습니다. 대본을 만든 날이 자동으로 들어가고,
> **영상 마지막 카드에만** 표시됩니다. 업로드 문구에는 날짜를 넣지 않습니다
> (다시 올릴 때 문구를 고쳐야 해서).

> 설치된 **Claude Code CLI**를 호출해서 분석합니다. 별도 API 키도, 추가 과금도 없습니다.
> CLI가 없으면 자동으로 수동 모드로 바뀝니다 —
> 지시문을 복사해서 클로드에 붙여넣고, 받은 JSON을 다시 붙여넣으면 됩니다.

### 2단계 · 대본 확인
카드별로 제목과 내레이션을 그 자리에서 고칠 수 있습니다.
**[미리보기]** 를 누르면 그 카드가 실제로 어떻게 보이는지 이미지로 확인됩니다.

### 3단계 · 녹음 🎙
카드마다 **대본이 크게 표시되고, 바로 아래에 녹음 버튼**이 있습니다.

- **[● 녹음 시작]** → 대본을 읽고 → **[■ 녹음 멈추기]** (스페이스바로도 멈춤)
- 바로 **재생해서 들어볼 수 있고**, 마음에 안 들면 **[다시 녹음]**
- 마음에 들면 다음 카드로. 상단 막대로 진행 상황이 보입니다
- **카드 길이는 녹음 길이에 맞춰 자동으로 조정됩니다** — 싱크를 맞출 필요가 없습니다
- **카드별 음량도 자동으로 고르게 맞춰집니다** (loudnorm, -16 LUFS).
  녹음할 때마다 목소리 크기가 달라도 이어 붙였을 때 들쑥날쑥하지 않습니다
- 녹음을 건너뛴 카드는 무음으로 처리되니, 일부만 녹음해도 됩니다
- **크롬·사파리 모두 됩니다.** 브라우저가 만들 수 있는 형식(크롬 webm / 사파리 mp4)을
  자동으로 골라 녹음하고, 서버에서 wav 로 변환합니다
- 녹음이 안 되면 **[마이크 점검]** 을 눌러보세요. 주소·권한·장치·녹음 형식을 순서대로 확인해 줍니다

### 4단계 · 최종 출력 + 올리기
합쳐진 내레이션을 **전체로 한 번 들어보고**, **[최종 영상 만들기]** 를 누르면
진행률이 표시되면서 렌더링됩니다. 끝나면 그 자리에서 **재생해보고 내려받기**.

**재생 속도**(보통 / 1.1배 / 1.25배)와 **카드 사이 여백**(0.25~0.4초)을 고를 수 있습니다.
누르면 바로 다시 합쳐져서 전체 길이가 갱신되니, 길이를 보며 맞추면 됩니다.
목소리도 같이 빨라지지만 **음정은 그대로** 유지됩니다(atempo).

> **2배속은 넣지 않았습니다.** 도표를 읽을 시간이 없어져 오히려 이탈이 늘고,
> 목소리가 부자연스러워져 "자동 생성 영상" 인상을 줍니다.
> 길이를 줄이려면 속도보다 **카드 수와 내레이션을 줄이는 쪽**이 낫습니다.

렌더가 끝나면 **영상(mp4)과 문구(txt)가 자동으로 다운로드 폴더에 저장됩니다.**
파일명은 `20260920-054631_카드포인트현금화.mp4` 처럼 **날짜시간_제목** 순서라
만든 순서대로 정렬됩니다.

> 브라우저가 "여러 파일 다운로드"를 물어보면 **허용**을 눌러주세요(처음 한 번만).
> 자동 저장이 막혔다면 화면의 [영상 내려받기] [문구(txt) 내려받기] 버튼으로 받으면 됩니다.

그 아래에 **올리기** 영역이 열립니다.

**플랫폼별 문구** — 유튜브 제목·설명·태그, 인스타 캡션(해시태그 5개),
쓰레드 문구가 대본에서 자동으로 만들어집니다. [복사] 버튼으로 가져다 쓰면 됩니다.
쓰레드는 그 플랫폼 말투에 맞춰 **반말·이모지로 친근하게** 나옵니다.

**유튜브 바로 올리기** — **비공개로 올리기**(기본) / 예약 발행 / 바로 공개 중에 고릅니다.
심사 전에는 예약·공개를 유튜브가 막을 수 있어서, 확실히 되는 비공개를 기본으로 둡니다.
처음 한 번만 설정이 필요합니다(아래 참고).

예약 발행을 고르면 **공개 시각이 자동으로 채워집니다.** 채널에 이미 예약해둔 영상 중
가장 늦은 시각을 찾아 **그 뒤 3~5시간 사이**를 랜덤으로 잡습니다(5분 단위).
한 시간대에 몰아서 올라가지 않게 하려는 것입니다. 마음에 안 들면 [다시 추천]을 누르거나
날짜·시각을 직접 고치면 됩니다. 예약된 영상이 없으면 지금부터 3~5시간 뒤로 잡습니다.

> 예약 목록을 읽으려면 `youtube.readonly` 권한이 필요합니다.
> **이 기능이 생기기 전에 계정을 연결했다면 [계정 연결 해제] 후 다시 연결**해주세요.
> 권한이 없어도 업로드는 그대로 되고, 추천 시각만 "지금 기준"으로 바뀝니다.

#### 다음 영상으로 넘어갈 때

맨 아래 **[전부 지우고 처음부터]** 를 누르면 원문·대본·녹음·합친 내레이션이 모두
지워지고 1단계로 돌아갑니다. 다음 작업의 4단계에 **이전 영상의 문구가 남지 않습니다.**
이미 만들어 둔 영상 파일(`output/`)은 지우지 않습니다.

> 문구는 언제나 **지금 대본**으로 다시 만들어집니다.
> `output/` 에 지난 영상이 남아 있어도, 그게 지금 대본보다 오래됐으면
> 완성본으로 치지 않아서 올리기 영역이 열리지 않습니다.

## 🛠 명령어

| 명령어 | 하는 일 |
| --- | --- |
| **`npm start`** | **브라우저 앱 실행 (http://localhost:4321)** |

| `npm run still -- 100` | 100번 프레임 한 장만 PNG로 확인 |

## ⌨️ 클로드코드에서 직접 쓰기 (앱 없이)

앱을 띄우지 않고 클로드코드에서 바로 작업할 수도 있습니다.
프로젝트 폴더에서 클로드코드를 켜고:

```
이 글로 쇼츠 만들어줘: [기사 전문 붙여넣기]
```

이때 쓰이는 명령들:

```bash
npm run narration           # 녹음용 대본 생성 → output/내레이션_*.md
npm run narration -- --fit  # 읽는 속도에 맞춰 카드 길이 재계산
npm run check               # 구조·독창성 점검
npm run render              # 렌더링
```

직접 녹음한 파일을 수동으로 얹으려면 `public/audio/` 에 넣고
`src/script.json` 에 `"narrationAudio": "audio/내파일.mp3"` 를 추가하면 됩니다.
(앱의 3단계를 쓰면 이 과정이 전부 자동입니다.)

## 📤 유튜브 업로드 설정 (처음 한 번만)

1. [Google Cloud Console](https://console.cloud.google.com/) 에서 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리** 에서 **YouTube Data API v3** 를 사용 설정합니다.
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   → 애플리케이션 유형 **데스크톱 앱** 으로 만듭니다.
4. ⭐ **[Google 인증 플랫폼 → 대상(Audience)](https://console.cloud.google.com/auth/audience)
   에서 본인을 "테스트 사용자"로 추가합니다.**
   (예전 화면이면 **OAuth 동의 화면 → 테스트 사용자**)
5. 나온 **클라이언트 ID / 클라이언트 보안 비밀** 을 앱 4단계의 입력란에 붙여넣고 저장.
6. **[구글 계정 연결]** 을 눌러 로그인하면 끝입니다.

### ❗ `git pull` 이 "Your local changes would be overwritten" 으로 막힌다면

```
error: Your local changes to the following files would be overwritten by merge:
        src/script.json
```

`src/script.json` 은 **영상을 만들 때마다 덮어써지는 작업 파일**입니다.
예전에는 이 파일이 저장소에 추적되고 있어서, 한 번이라도 영상을 만들면
그 뒤로 `git pull` 이 계속 막혔습니다. **지금은 추적하지 않습니다**(틀은
`src/script.default.json` 에 있고, 없으면 자동으로 만들어집니다).

한 번만 아래처럼 정리하면 그 뒤로는 안 생깁니다.

```bash
cp src/script.json ~/script-backup.json   # 작업 중이던 대본을 남겨두고 싶다면
git checkout -- src/script.json
git pull
npm install
```

### ❗ `npm start` 가 `EADDRINUSE ... port 4321` 로 죽는다면

**예전에 켜둔 서버가 아직 돌고 있습니다.** 이때 브라우저를 열면 화면은 나오지만
**예전 코드가 응답**해서, 고친 내용이 반영되지 않습니다.

```bash
# macOS / Linux
lsof -ti:4321 | xargs kill

# Windows
netstat -ano | findstr :4321
taskkill /PID <번호> /F
```

정리한 뒤 `npm start` 를 다시 하고, 터미널에 찍히는 **버전**과
화면 오른쪽 위의 버전이 같은지 확인해주세요.

### ❗ "fetch failed" 만 뜬다면

Node 의 `fetch` 는 어떤 이유로 실패하든 메시지가 **"fetch failed" 한 줄**이라,
그대로 보여주면 아무 단서도 남지 않습니다. 지금은 앱이 진짜 원인
(`ECONNRESET`, 타임아웃, 길이 불일치 등)을 **"원인:" 줄에 풀어서** 보여줍니다.
그 줄이 안 보인다면 예전 코드가 돌고 있는 것이니 **서버를 껐다 다시 켜주세요**
(터미널에서 `Ctrl+C` → `npm start`).

**이 오류가 떴는데 영상이 유튜브에 올라가 있을 수 있습니다.** 영상이 다 도착한 뒤에
응답만 못 받는 일이 있기 때문입니다. 그래서 앱은 끊기면 **다시 올리지 않고**
"다 받았냐"고 먼저 물어봅니다 — 다 받았으면 그대로 성공으로 처리합니다.
(예전에는 다시 올려서 **같은 영상이 두 개** 올라갔습니다. 스튜디오에서 중복을 지우세요)

### ❗ 일주일쯤 지나면 연결이 끊깁니다

**"테스트" 상태에서 발급된 토큰은 구글이 7일 뒤에 만료시킵니다.** 정책이라 우회할 수 없습니다.
예약 발행을 걸어두고 7일이 지나면 업로드가 실패하므로, 계속 쓰실 거라면
[대상(Audience)](https://console.cloud.google.com/auth/audience) 에서
**앱 게시 → 프로덕션** 으로 바꿔두세요. (프로덕션에서는 토큰이 만료되지 않습니다)

입력한 값과 토큰은 `app/data/youtube.json` 에만 저장되고 저장소에 올라가지 않습니다.

### ⚠️ 심사를 받기 전에는 비공개로만 올라갑니다

구글 API 심사를 받지 않은 프로젝트로 업로드한 영상은 **강제로 비공개**가 되고,
나중에 수동으로도 공개로 바꿀 수 없습니다(재업로드해야 합니다).
공개로 올리려면 [API 감사](https://support.google.com/youtube/contact/yt_api_form) 를 먼저 통과해야 합니다.

**예약 발행도 마찬가지입니다.** 심사 전에는 예약 시각이 와도 공개되지 않을 수 있습니다.

심사 전이라면 이렇게 쓰는 걸 권합니다.
- 이 앱에서는 **비공개로만 올리기**로 백업해두고
- 실제 공개·예약은 유튜브 스튜디오에서 직접

### 할당량

업로드 1건에 1600 units 를 쓰고 기본 한도가 하루 10,000 units 라
**하루 약 6개**까지만 올라갑니다. 초과하면 다음 날까지 기다려야 합니다.

### 인스타그램 · 쓰레드는?

API 로 바로 올리려면 Meta 앱 심사와 비즈니스 인증, 그리고 영상을 올려둘
**공개 URL 호스팅**이 필요합니다(두 API 모두 파일 직접 업로드를 받지 않습니다).
지금은 **문구만 자동으로 만들어 복사**할 수 있게 해뒀습니다.

## ❓ 자주 막히는 곳

**렌더링할 때 Chrome 다운로드가 실패해요**
```powershell
$env:REMOTION_BROWSER_EXECUTABLE="C:\Program Files\Google\Chrome\Application\chrome.exe"
npm run render
```

**글자가 네모(□)로 나와요** → `node scripts/setup-fonts.mjs` 실행

**영상이 너무 길어요** → 내레이션을 줄이고 `npm run narration -- --fit`

**도표가 안 나와요** → `npm run check` 로 `visual` 형식 확인, [docs/VISUALS.md](./docs/VISUALS.md) 참고

**녹음한 소리가 처음엔 크다가 점점 작아져요**
→ 고쳐졌습니다. `git pull` 후 **다시 녹음**해주세요.
   브라우저의 자동 이득 조절(AGC)이 녹음 중에 볼륨을 계속 낮추던 문제였습니다.
   이제 AGC를 끄고 녹음하고, 음량은 합칠 때 한 번에 고르게 맞춥니다.
   **이미 녹음해둔 파일은 그 변화가 이미 들어가 있어서 다시 녹음해야 합니다.**

**앱에서 마이크가 안 잡혀요**
→ 3단계 상단의 **[마이크 점검]** 을 눌러주세요.
   주소·사이트 권한·입력 장치·실제 열기를 각각 확인해서 어느 단계에서 막혔는지 알려줍니다.

   특히 **사이트 권한은 허용인데 열리지 않는 경우**는 브라우저 위 단계가 원인입니다.
   1. 윈도우 설정 → 개인 정보 및 보안 → 마이크 →
      "마이크 액세스", "앱이 마이크에 액세스하도록 허용", 목록의 브라우저까지 모두 켜기
   2. 설정을 바꿨으면 브라우저를 완전히 종료했다가 다시 켜기
   3. 회사 PC라면 보안 정책일 수 있습니다 (`chrome://policy` 에서 `AudioCaptureAllowed` 확인)

   그래도 안 되면 휴대폰 녹음기로 녹음한 파일을 `public/audio/` 에 넣고
   `src/script.json` 에 `"narrationAudio": "audio/내파일.mp3"` 로 지정하면 됩니다.

**"대본 생성 수동 모드"로 표시돼요**
→ Claude Code CLI를 찾지 못한 경우입니다. 설치돼 있다면 `claude --version` 이
   터미널에서 되는지 확인하세요. 수동 모드로도 전부 쓸 수 있습니다.

**포트 4321이 이미 쓰이고 있어요**
```bash
PORT=5000 npm start          # macOS / Linux
$env:PORT=5000; npm start    # Windows PowerShell
```

**"설치가 덜 됐습니다" 빨간 안내가 떠요**
→ `npm install` 을 아직 안 했거나 중간에 실패한 경우입니다.
   터미널에서 `Ctrl+C` 로 서버를 끄고, 프로젝트 폴더에서 `npm install` 을 실행한 뒤
   `npm start` 로 다시 켜주세요. 어떤 게 빠졌는지는 안내에 그대로 적혀 있습니다.

**`npm error could not determine executable to run`**
→ 같은 원인입니다(패키지 미설치). `npm install` 후 다시 시도하세요.

**`npm error EACCES ... ~/.npm/_cacache`** (맥)
→ npm 캐시 폴더에 root 소유 파일이 섞인 경우입니다.
   과거에 `sudo npm install` 을 한 번이라도 쓰면 이렇게 됩니다.
```bash
sudo chown -R $(whoami) ~/.npm
npm install
```
   sudo 를 쓰기 싫으면 캐시를 따로 쓰면 됩니다: `npm install --cache ~/.npm-shorts`

**`분석 실패 (code 1)` 과 함께 글자가 깨져 나와요** (윈도우)
→ 고쳐졌습니다. `git pull` 후 다시 실행하세요.
   사용자 이름에 한글이 들어간 경로(`C:\Users\홍길동\...`)에서 claude 실행 파일을
   찾을 때 경로가 깨지던 문제였습니다.
   서버 시작 화면에 찾은 claude 경로가 표시되니, 그래도 안 되면 그 줄을 확인하세요.

**`Library not loaded: libavdevice.dylib`** (맥)
→ 고쳐졌습니다. `git pull` 후 다시 실행하세요.
   ffmpeg 가 쓰는 라이브러리는 바이너리 옆에 있는데, macOS 는 이를 작업 디렉터리
   기준으로 찾습니다. 이제 바이너리가 있는 폴더에서 실행합니다.
